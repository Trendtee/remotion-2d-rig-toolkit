# Contributing

Issues and small pull requests are welcome. Please start with a reproducible example.

1. Fork the repository and create a topic branch.
2. Run `npm install && npm test`.
3. Add tests for behavioral changes, especially pickup/release continuity and unreachable IK targets.
4. Avoid adding characters, brand assets, voice recordings, scripts, or other media you do not have the rights to redistribute.
5. Describe the expected geometry in screen coordinates (positive y downward).

Please do not include secrets or account tokens in issues or test fixtures.
