# Security policy

## Scope

`remotion-2d-rig-toolkit` performs local, deterministic geometry calculations. It has no runtime dependencies, makes no network requests, reads no files and collects no data. The example Remotion project uses Remotion and React as development dependencies.

## Supported versions

| Version | Supported |
| --- | --- |
| 0.2.x | ✅ |
| < 0.2 | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/Trendtee/remotion-2d-rig-toolkit/security/advisories/new).

Expect an acknowledgement within 7 days. Never include credentials, tokens or private assets in a report.
