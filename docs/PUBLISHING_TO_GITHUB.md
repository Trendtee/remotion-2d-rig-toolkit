# Repository maintainer instructions

The initial public repository has been created at https://github.com/Trendtee/remotion-2d-rig-toolkit.

## Working on the code

```bash
git clone https://github.com/Trendtee/remotion-2d-rig-toolkit.git
cd remotion-2d-rig-toolkit
npm install
npm test
```

Publish source changes through pull requests or commits after review. The `dist/` folder is generated by `npm run build` and intentionally ignored by Git.

## Privacy and licensing checks

- Do not include private scripts, character artwork, unpublished video, voice recordings, tokens, or proprietary project assets.
- Verify that changes are correctly licensed and that added third-party code or media may be redistributed.
- This is a new v0.1.0 prototype, not evidence of proven ecosystem reach or automatic eligibility for external open-source contributor programs.
